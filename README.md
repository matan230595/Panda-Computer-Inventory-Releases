# Panda Computer Inventory - Releases

Download page for **Panda Computer Inventory**: a free, read-only hardware and software inventory tool for Windows (Hebrew and English).

- Product page and download form: https://computerinventory.panda-il.com/
- Support: ComputerInventory@panda-il.com
- Developed by Panda Digital & AI Agency, https://www.panda-il.com

This repository only hosts the release files. Each release lists a SHA-256 for every file.

Verify a download in PowerShell:

    Get-FileHash .\PandaComputerInventory-v1.9.1.zip -Algorithm SHA256
